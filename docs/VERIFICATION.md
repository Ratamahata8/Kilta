# Проверки редакции 2 — 8 октября 2026

## Реальный каталог и анимации

После наполнения из `kilta-content` прошли TypeScript, ESLint, 13 unit-тестов, 17 сценариев PostgreSQL и production demo build с base `/Kilta/`. Все 100 доступных оригиналов проверены по SHA-256; 14 изделий и 8 категорий сверены с `catalog.json`, включая точные описания, цены, текстовые размеры и порядок доступных фотографий. Размеры всех 168 WebP дополнительно сверены с подготовленными метаданными. Два отсутствующих файла перечислены в [CONTENT_IMPORT](CONTENT_IMPORT.md); повреждённых файлов и отсутствующих ссылок в сборке нет.

Браузерный набор расширен до 11 сценариев на production builds: все 14 страниц изделий и их фотографии; hover/focus и быстрые повторные наведения во всех трёх темах без скачка сетки; медленная загрузка следующего слайда; crossfade, клавиатура, Tab/Shift+Tab и Escape в lightbox; touch на 360 px, первый tap и настоящий свайп; reduced-motion и отсутствие IntersectionObserver; read-only демо без запросов к Supabase; ошибки конфигурации/сети; загрузка, draft/preview/publish и тема; история документов и PDF. Отдельный сценарий проверяет, что предпросмотр импорта показывает исходный каталог, не меняя существующие черновики и публикации. Главная и изделие просмотрены по мобильным и десктопным снимкам; все фото главной загрузились без горизонтального переполнения.

Все 11 браузерных сценариев прошли одним запуском после последних изменений.

Unit-проверки импорта подтверждают порядок создания зависимостей, перенос ссылок на настоящие UUID, сохранение клиентских изменений/переименований/архивных записей при повторе, повторное чтение после предпросмотра и отказ до загрузки при неверной контрольной сумме. SQL исполняет обе migrations и проверяет размеры опубликованных изображений, новые поля и ссылки, сохраняя прежние ограничения доступа. Это локальная проверка: реальный Supabase Auth/Storage и облачный импорт не запускались.

Pages workflow сохраняет `main`, read-only `demo` по умолчанию и отдельную проверку PR без публикации. В artifact только frontend и выбранные WebP: оригиналы, сохранённые HTML и `.env` не попадают. Основной JS — около 648 КБ / 181 КБ gzip; предупреждение Vite о размере chunk неблокирующее, админка загружается отдельно. Удалённый запуск Actions и создание PR через API пока недоступны (`Forbidden`); видимость, домен и облачная инфраструктура не менялись.

## Выполнено в облачной среде разработки

- Установка через `npm ci`, TypeScript, ESLint и production build прошли на Node.js 24.19.0. Сборка — статический `dist/`, по умолчанию base `/Kilta/`. Отдельная сборка под `/` проверена в браузере: прямой hash-маршрут, refresh, изображения и недоступность входа в read-only демо.
- 6 unit-тестов: границы публичной конфигурации, безопасные URL/rich text, валидация цены/даты, ссылки на медиа и оглавление.
- 16 сценариев PostgreSQL: настоящая миграция, RLS/grants, роли owner/developer/outsider/anon, запрет повышения роли, приватные данные, публикация отдельного снимка, защита файлов и связей, конфликт редакций, стабильный адрес документа, восстановление в новый черновик, закрытые заявки, ограничения buckets и идемпотентный seed.
- 5 браузерных сценариев на production builds: 360/768/1440 px, три темы, контраст основного текста, отсутствие горизонтального скролла, клавиатура и refresh hash-маршрутов; отсутствие конфигурации, пустой каталог и сетевой отказ; загрузка двух JPEG с производными WebP, порядок галереи, preview/draft/publish, независимый посетитель и изменение темы; история rich-text документа; PDF в отдельном публичном bucket и ссылка скачивания.
- Дополнительно по вычисленным CSS-переменным проверены 9 сочетаний темы/акцента: основной текст, подписи на фоне/панелях, акцент и пары цветов кнопок имеют контраст не ниже 4.5:1. Десктопная и мобильная главная просмотрены по снимкам production preview.

Все пять браузерных сценариев прошли одним запуском после последних изменений. Они используют подменённый Supabase transport. SQL исполняется в изолированной базе настоящего PostgreSQL, но `auth` и `storage` — тестовые fixtures. Эти проверки **не подтверждают реальную облачную авторизацию, работу Storage gateway и сохранение между устройствами**.

У Vite есть неблокирующее предупреждение: основной JS chunk превышает 500 КБ (около 150 КБ gzip). Админка загружается отдельным chunk по требованию.
