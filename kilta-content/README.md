# Материалы KILTA для заполнения сайта

Собрано 8 октября 2026 года с https://kilta.ru/ .
Содержимое: 14 изделий, 8 категорий, 102 уникальных изображений (включая логотипы, изображения категорий и служебных страниц).

## Как добавить в репозиторий

Распакуйте архив. Добавьте папку `kilta-content` целиком в корень репозитория `Ratamahata8/Kilta`. Передайте Codex файл `CODEX_IMPORT_AND_MOTION.md`.
Не помещайте ZIP в репозиторий вместо распакованной папки: Codex нужны доступные файлы и JSON.

## Файлы

- `catalog.json`: 14 изделий, исходные описания, цены, материалы, размеры, упорядоченные галереи и категории.
- `images/`: скачанные оригиналы, опубликованные на CDN сайта; имена с хешем предотвращают коллизии вроде `photo.jpg`.
- `pages.json`: извлечённые тексты, блоки, ссылки и изображения всех обнаруженных страниц.
- `pages/*.md`: чистые описания изделий. `*.txt`: текст страниц для сверки.
- `assets.json`: исходные URL, локальные пути, размеры, контрольные суммы.
- `source-html/`: снимки исходной/отрендеренной разметки для сверки, НЕ для встраивания в новый сайт.
- `ANIMATION_BRIEF.md`: анализ текущего наведения и спецификация улучшений.
- `motion-preview.html`: прототип эффектов с реальными фото, открывается локально после распаковки.
- `extraction-report.json`: охват и ошибки извлечения.

## Точность

Цены и характеристики сохранены по источнику на дату выгрузки и требуют подтверждения владельца перед реальным запуском. Ничего не исправлялось догадками. В My space источник указывает В1900 мм — проверьте размер с владельцем.
Фотографии — оригинальные файлы, доступные посетителю сайта, а не исходники фотографа. Архив охватывает страницы, доступные через меню и карточки каталога; отсутствие скрытых страниц подтвердить нельзя.
На сайте нет найденной страницы оферты: не создавать её текст из предположений. Политика сохранена для сверки; старые домены и юридические сведения требуют актуализации владельцем.
Авторство изображений принадлежит KILTA. Материалы предназначены для переноса сайта заказчика с его разрешения; уведомление об авторских правах сохранено в снимках страниц.
